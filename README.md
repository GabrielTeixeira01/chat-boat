💻 Desenvolvi uma API REST para gerenciamento de pedidos utilizando Node.js, Express e MySQL, com foco em praticar conceitos fundamentais de backend e integração com banco de dados.

A aplicação permite:

 Criação de pedidos com dados como cliente, produto e quantidade
Armazenamento das informações em banco de dados MySQL
Listagem de todos os pedidos cadastrados
Atualização do status dos pedidos (ex: PENDENTE, APROVADO)
Os dados são manipulados em formato JSON, seguindo o padrão de comunicação de APIs REST.
A estrutura do projeto foi organizada utilizando rotas separadas, facilitando a manutenção do código.
Também implementei uma rota de webhook para simular o recebimento de dados de sistemas externos, como chatbots e plataformas omnichannel.
